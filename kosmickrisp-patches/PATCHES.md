# KosmicKrisp source adaptations

MacLauncher KosmicKrisp applies the following source adaptations to the Mesa revision selected by [kosmickrisp-source.json](../kosmickrisp-source.json). Mesa references without a fixed revision use that source pin. Capabilities implement missing Vulkan features, extensions, properties or limits. Corrections repair behavior already exposed by upstream. Compatibility adaptations provide a consumer interface. Diagnostics add opt-in measurement or capture without changing default behavior. Documentation adaptations describe the adapted driver. The [ordered registry](registry.mjs) composes one module per adaptation through the existing source projection. [patches.json](patches.json) records capabilities, affected contracts, consumers, upstream relationships, replacement conditions and verification targets.
